# Dicionário do mapa
Cada linha é uma proposta, não uma publicação. id é estável; proposed_path preserva URL existente quando possível; existing_url é o endereço atual correspondente; page_type distingue service/hub/article. cluster reúne necessidades relacionadas; audience define leitor; primary_intent e primary_topic delimitam resposta; secondary_queries aguardam pesquisa individual. business_value conecta decisão à oferta; demand_evidence não equivale a volume; original_contribution explica ganho específico; source_ids aponta fontes candidatas em sources.md.
commercial_claims_status e author_reviewer impedem alegações/autoria inventadas. parent_page e internal_links_in/out definem arquitetura pretendida, não links a rascunhos públicos. canonical_strategy conserva legados enquanto não houver versão própria aprovada. cta é próxima ação; priority e effort orientam lotes; content_status separa brief/rascunho/revisões/aprovado/publicado; publication_blocker é dependência concreta.
Contagem: 12 serviços + 6 hubs substanciais + 72 artigos/guias = 90 propostas. Não inclui aliases, legais, filtros, cidades artificiais ou cases sem prova. Similaridade de intenção é revisão humana, não apenas comparação de slugs.
